# Silver: `product_id`

Группа primary key: `product_id`; ключевые колонки типов `DATE` и `TIMESTAMP`, включая
`calculated_at`, в имя директории не включаются.

- [`product_feedback_counts_12h`](product_feedback_counts_12h/v1/README.md) — аддитивные 12-часовые feedback-факты товара.
- [`product_search_queries`](product_search_queries/v1/README.md) - поисковые запросы по product_id из ranking candidates за 14 дней.
