# Gold: `query`

Грейн группы: `query`; `date` исключена из имени группы.

- [`search_query_atc_features`](search_query_atc_features/v1/README.md) — показы, ATC и заказы по нормализованному поисковому запросу.
- [`search_query_atc_features_qid`](search_query_atc_features_qid/v1/README.md) — показы, ATC и заказы по поисковому запросу, посчитанные в рамках каноничного `query_id` и развёрнутые обратно на исходные `query_text`.
