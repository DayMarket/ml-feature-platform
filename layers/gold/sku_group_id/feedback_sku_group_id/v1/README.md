# Gold-фичи отзывов по SKU Group ID

DAG id: `feature-platform.layers.gold.sku_group_id.feedback_sku_group_id`.

Пайплайн строит дневный снимок базовых фичей отзывов и рейтинга на уровне `sku_group_id`.

Целевая таблица: `iceberg.gold.feature_platform_sku_group_feedback_base_stats`.

Основная логика:

- читает опубликованные отзывы из `iceberg.silver_bxappdb2_foodback.public_feedback`;
- обогащает отзывы SKU-данными из `iceberg.silver.sku`;
- собирает всю историю опубликованных отзывов до начала расчетной даты Airflow `ds`, то есть состояние на вчерашний день;
- агрегирует отзывы на уровень `sku_group_id`;
- считает средний рейтинг, хорошие и плохие отзывы;
- считает распределение отзывов по оценкам 1-5;
- считает количество отзывов с непустым текстом;
- считает доли оценок, плохих отзывов и хороших отзывов от общего количества отзывов;
- пишет результат в Iceberg через `overwritePartitions()`.

Партиция результата соответствует Airflow `ds`.

## DQ

DQ-тесты выполняются таской `dq` внутри этого DAG'а сразу после записи партиции;
каталог тестов и правила конфигурирования описаны в `dq/README.md`.

Базовый набор: `primary_key_not_null`, `primary_key_unique`, `row_count_min`,
`row_count_growth`, `freshness`.

Пороги подобраны по истории таблицы в Trino (234 партиции с 2026-01-01):

- `row_count_min: 1700000` — минимум за последние 30 партиций 2.06M строк, объём
  только растёт;
- `row_count_growth: 0.02` — таблица кумулятивная, в каждой партиции лежит срез
  отзывов «за все время». По 233 парам соседних партиций прирост лежит в
  +0.04%..+0.33% и ни разу не был отрицательным. Тот же порог, что у product-уровня
  этой витрины.

Дополнительно `not_null` и `non_negative` по всем 17 фичевым колонкам. `product_rating`
вынесен в отдельный `not_null` с `severity: warn`: пустой AVG(rating) означает, что ни
у одного опубликованного отзыва нет оценки — аномалия источника, но не повод ронять
DAG. Поведение совпадает с `layers/gold/product_id/feedback_product_id/v1`.

Аплоад ranking-фич ждёт таску `dq` этого DAG'а, а не весь DAG и не dbt-DQ-DAG.
