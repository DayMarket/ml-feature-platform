# Gold: `category_id_query_text`

Грейн группы: `category_id,query_text`; `date` исключена из имени группы.

- [`query_category_relevance`](query_category_relevance/v1/README.md) — метка релевантности категории-кандидата поисковому запросу.
- [`query_category_relevance_expanded`](query_category_relevance_expanded/v1/README.md) — та же метка, разложенная на все формулировки `query_id` (`lower`, одна строка на пару); источник upload'а в ranking-service.
